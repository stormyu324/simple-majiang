# 简单麻将

一个在命令行里玩的简单麻将游戏：你和 3 个电脑对手打一局。

## 运行

需要 Node.js 18 或更高版本，不需要安装任何依赖。

```bash
npm start      # 开始游戏
npm test       # 运行测试
```

## 规则

- 136 张牌：万、条、筒各 1-9，字牌东南西北中发白，每种 4 张
- 每人起手 13 张，轮流摸一张、打一张
- 可以**碰**别人打出的牌（手里有一对相同的牌）
- 胡牌方式：
  - 标准胡：4 组面子（顺子或刻子）+ 1 对将
  - 七对：7 个对子
- 可以**自摸**，也可以胡别人打出的牌（点炮）
- 牌墙摸完没人胡就流局

没有吃、杠和番数计算，保持简单。

## 代码结构

```
index.js         命令行入口
src/tiles.js     牌的表示、名称、洗牌
src/rules.js     胡牌、碰牌判定
src/ai.js        电脑的出牌策略
src/game.js      游戏流程
test/            测试
```
