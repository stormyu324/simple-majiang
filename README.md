# 简单麻将

网页麻将游戏，支持多种地方玩法，可以单人和电脑打，也可以和好友联网对战、观战。另有一个命令行版（新手简单玩法）。

## 运行

需要 Node.js 18 或更高版本，不需要安装任何依赖。

```bash
npm run web    # 网页版：自动在浏览器打开 http://localhost:8080/
npm start      # 命令行版
npm test       # 运行测试
```

网页版不能直接双击 `web/index.html` 打开（浏览器不允许本地文件加载模块代码），要用 `npm run web`。

## 好友对战和观战（网页版）

打开网页先选模式：**单人练习**（和电脑打）或**好友对战**。

- **创建房间**拿到 4 位房间号，点"复制邀请链接"发给好友；好友打开链接点"加入"
- 最多 4 个人，房主可以选玩法，随时可以开局，空座位由电脑来打
- 对局中有人掉线，电脑先替他打；他刷新页面或重新连上后接着自己打
- 出牌限时 30 秒，胡/碰 限时 15 秒，超时自动处理
- **观战**：输入房间号点"观战"。观战的人只能看到打出的牌、碰出的牌和每家张数，一局结束后才翻开所有手牌。两局之间有空位时可以点"入座"
- 牌局全部在服务器上判定，每个人只收到自己能看的牌，打开开发者工具也看不到别人的手牌

好友对战需要房间服务器，只能在 games.stormnovalabs.com/majiang/ 上玩；GitHub Pages 和 `npm run web` 只能单人练习。本地测试好友对战用：

```bash
npm run build && npx wrangler dev   # 打开 http://localhost:8787/majiang/
```

## 玩法

打开网页先选玩法。每种玩法的完整规则在游戏里点"📜 玩法规则"查看（规则写在 `src/variants.js` 里）。各地规则差别很大，这里按最常见的打法来做。

| 玩法 | 人数 | 牌 | 特点 |
|---|---|---|---|
| 武汉麻将（红中赖子杠·开口翻） | 4 | 136 张 | 翻牌定赖子，红中和皮子要杠掉，必须开口，小胡 258 将，番数翻倍算分，封顶/金顶 |
| 武汉麻将（口口翻） | 4 | 136 张 | 同上，每开一次口都翻一番 |
| 卡五星 | 3 | 84 张（条筒+中发白） | 不能吃，亮倒，卡五星、四归一、手抓一、三元等番型 |
| 武汉晃晃 | 4 | 120 张（万条筒+中发白） | 不能吃、不用开口，翻牌定赖子，红中杠，七对 |
| 红中麻将 | 4 | 112 张（万条筒+红中） | 红中是万能牌，只能自摸，抓码 |
| 四川血战到底 | 4 | 108 张（万条筒） | 换三张、定缺，一家胡了接着打，一炮多响，刮风下雨，查花猪查大叫 |
| 新手简单玩法 | 4 | 136 张 | 只碰不吃，没有赖子，适合入门 |

每局结束显示番型和本局得分，多局累计总分（换玩法时清零）。

## 新手教学（网页版）

- **📖 新手教学**：14 步从零教起——认牌、面子和将、胡牌公式、一回合怎么打、听牌、出牌技巧，中间有 4 道小测验。第一次打开网页会自动弹出。
- **提示**：打开后，轮到你时会高亮建议打的牌，并显示你现在听哪些牌（按当前玩法的规则算）。学完教学会自动打开。
- **🔍 大牌**：所有牌放大 1.25 倍，看不清牌的时候打开。
- **🔊 声音**：音效（洗牌发牌、出牌、碰杠、倒计时）、配音（报牌名、喊吃碰杠胡，用浏览器自带的中文语音）、古筝风格的背景音乐，都可以单独开关、调音量。声音全部在浏览器里现场合成，不需要音频文件。

## 代码结构

```
index.js           命令行入口（新手简单玩法）
src/tiles.js       牌的表示、名称、洗牌
src/rules.js       胡牌、碰牌判定（命令行版和新手教学用）
src/ai.js          电脑的出牌策略（命令行版用）
src/game.js        命令行版的游戏流程
src/hand.js        带赖子的胡牌判定、七对、向听数
src/engine.js      网页版和服务器共用的牌局流程：吃碰杠、特殊杠、换三张、定缺、亮倒、血战
src/variants.js    各地玩法的规则和算分
src/bot.js         网页版和服务器的电脑玩家
web/index.html     网页版页面
web/main.js        网页版界面：菜单、等候室、渲染牌桌、处理点击
web/online.js      好友对战：创建房间、WebSocket 连接和断线重连
server/worker.js   Cloudflare Worker 入口：/majiang/api/* 交给房间，其他是静态文件
server/room.js     房间服务器（Durable Object）：座位、观战、牌局判定
web/tile-art.js    用 SVG 画牌面
web/sound.js       音效、配音、背景音乐（Web Audio 合成 + 浏览器语音）
web/announcer.js   根据画面变化决定放什么声音、喊什么
web/tutorial.js    新手教学和小测验
web/style.css      样式
web/server.js      本地静态服务器（npm run web）
test/              测试
```
